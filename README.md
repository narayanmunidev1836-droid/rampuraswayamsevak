# Rampura Swayamsevak Form

Next.js (JavaScript) + MongoDB project.

## Run
1. `npm install`
2. Copy `.env.example` to `.env.local` and set MongoDB, admin credentials and AUTH_SECRET.
3. `npm run dev`
4. Public form: `/`
5. Admin: `/admin`

Admin can view all submitted users and click Print. The print page uses the supplied Dholera Dham form artwork as the A4 template and overlays submitted data.
